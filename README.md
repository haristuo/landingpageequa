# Sunrise Collective

Eine fiktive Non-Profit-Landingpage zum Testen des eingebundenen Whitelabel-Staging-Widgets.

## Entwicklung

```bash
npm install
npm run dev
```

## Produktion

```bash
npm run lint
npm run build
```

Die Markenassets liegen in `public/brand`, die Bildwelt in `public/images`.
